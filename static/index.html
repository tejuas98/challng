Welcome to SchemForge — Circuit Studio Guide
SchemForge creates visual electrical schematic questions with verified step-by-step proofs, checks every drawing for zero overlapping labels, and tests whether Vision AI models actually trace wires and symbols instead of guessing from printed text. Ready-made question sets are loaded so you can explore right away.
Browse Questions — Verified Answers & Clarity Switch between the 6 built-in sets (Default Mix, Easy Practice, Medium Challenge, Hard Exam, Switches & Logic, Resistors & Ohms) at top-left, filter by Topic/Difficulty/Scan Look, or click any schematic image to zoom in. Each item shows the verified answer, overlap check, OCR readout, and exact trace steps.
Create Question Bank — Custom Sets & .ZIP Use the top Create Custom Question Set panel to generate 1 to 25,000 non-repetitive questions with live countdown progress, or pick any pre-built set in Question Sets & Bank Library below to browse or download a portable .ZIP (Quiz Booklet HTML + Excel CSV + PNGs). Quick Try Live Preview lets you test single circuits interactively.
Build Your Own Circuit — Live Topology Compiler Load a starter circuit example or write simple wire paths (such as VCC1(12V) -> SW1(CLOSED) -> U1(AND) -> L1). SchemForge renders the drawing and recalculates the exact answer & steps live as you type, and can expand any custom circuit into up to 10,000+ unique variations.
AI Test Scores — Vision Comparison & Checks Run Vision AI models (Google Gemini, OpenRouter, Local Ollama, or add Claude / OpenAI / any custom API key via + Add Model / Key) side-by-side against Word Reader and Random Guess baselines, inspect exact missed questions below the chart, and run all 12 broken-circuit guardrail tests live.
Quick Studio Overview: Open Hard Exam Pack in Browse Questions to inspect symbol-only schematics and traces; use Create Question Bank to download a .ZIP or generate custom batches with live progress; flip a switch state (CLOSED ↔ OPEN) in Build Your Own Circuit to watch the schematic recalculate live; compare Vision AI against Word Reader and inspect Visual Proof in AI Test Scores.
